## Learning Path

A practical progression through this collection is:

1. Begin with **Auth Lockdown Recon** and **Credential Trail** to practice authentication-focused reconnaissance.
2. Continue with **Subdomain Shell Hunt** and **DNS Ghosts: Template Tricks** for DNS and subdomain discovery.
3. Explore **Stream Sleuth** and **Hosts File Hijack 2** for additional web and network investigation.
4. Study **Tornado Template Trap** and **Template Trap: SSTI to Root** to understand template injection and SSTI concepts.
5. Move to **RCE Relay** to study remote code execution concepts in the controlled lab.
6. Continue with **XXE Trail: Blackhat Secrets** and **XXE Secrets: File Leak to Login** for XML and XXE security.
7. Finish with **XML Echo to Root** for a broader XML-to-root CTF challenge.

## How to Use the Labs

- Read each lab's instructions before starting.
- Work only inside the authorized CTF or training environment.
- Record discovered domains, subdomains, endpoints, parameters, and application behavior.
- For SSTI challenges, understand how template processing creates the security issue.
- For RCE exercises, document the vulnerability concept rather than applying it to unrelated systems.
- For XXE labs, study how XML processing can expose unintended information.
- Treat credentials and discovered files as lab-only information.
- Never use these techniques against systems without explicit authorization.
